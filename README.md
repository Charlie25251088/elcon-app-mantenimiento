# ELCON App Mantenimiento

Aplicación móvil para la gestión de mantenimiento preventivo y correctivo de sistemas de seguridad electrónica de la empresa ELCON.

## Descripción

El proyecto busca optimizar la gestión de las actividades de mantenimiento de sistemas de videovigilancia, alarmas, sistemas contra incendios y redes, facilitando el registro, seguimiento y control de las actividades técnicas.

## Funcionalidades principales

- Gestión de usuarios y roles.
- Gestión de clientes.
- Gestión de equipos instalados.
- Gestión de mantenimientos preventivos.
- Gestión de mantenimientos correctivos.
- Registro y seguimiento de incidencias.
- Registro de evidencias técnicas.
- Generación de reportes.

## Tecnologías

- Ionic
- Angular
- Node.js
- API REST
- Base de datos relacional
- Git y GitHub

## Estructura del proyecto

- `mobile/` — Aplicación móvil
- `backend/` — Servicios y API
- `database/` — Scripts y estructura de base de datos
- `docs/` — Documentación del proyecto
