# Requisitos Iniciales

## Requisitos funcionales

- RF01: El sistema permitirá gestionar usuarios y roles.
- RF02: El sistema permitirá registrar clientes.
- RF03: El sistema permitirá registrar equipos de seguridad electrónica.
- RF04: El sistema permitirá registrar mantenimientos preventivos.
- RF05: El sistema permitirá registrar mantenimientos correctivos.
- RF06: El sistema permitirá registrar y consultar incidencias.
- RF07: El sistema permitirá registrar evidencias de las actividades realizadas.

## Requisitos no funcionales

- RNF01: El sistema deberá implementar autenticación de usuarios.
- RNF02: El sistema deberá controlar el acceso según el rol del usuario.
- RNF03: La información deberá almacenarse de forma segura.
- RNF04: El sistema deberá mantener trazabilidad de las modificaciones realizadas.
- RNF05: La aplicación deberá contar con una interfaz adecuada para dispositivos móviles.
