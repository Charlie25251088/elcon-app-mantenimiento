# Auditoría Funcional

## Requisito evaluado

RF04: El sistema permitirá registrar mantenimientos preventivos.

## Estado de implementación

El proyecto se encuentra en una etapa inicial de desarrollo. Actualmente la aplicación móvil todavía no cuenta con la implementación funcional del módulo de registro de mantenimientos preventivos.

## Criterios de aceptación

| Criterio | Estado | Observación |
|---|---|---|
| Registrar un mantenimiento asociado a un equipo | Pendiente | La funcionalidad aún no ha sido implementada. |
| Validar los campos obligatorios antes de guardar | Pendiente | El formulario funcional aún no está implementado. |
| Almacenar y consultar el mantenimiento registrado | Pendiente | La persistencia de información aún no ha sido implementada. |

## Resultado de la auditoría

El requisito RF04 fue identificado y definido junto con sus criterios de aceptación. Sin embargo, no es posible aprobar funcionalmente el requisito en la línea base actual debido a que el módulo correspondiente todavía se encuentra pendiente de desarrollo.

## Acción pendiente

Implementar el módulo de registro de mantenimientos preventivos y ejecutar nuevamente las pruebas funcionales cuando la aplicación cuente con dicha funcionalidad.

## Conclusión

La auditoría permite establecer una línea base clara del estado actual del requisito y deja registrados los criterios que deberán verificarse antes de considerar funcionalmente aprobado el módulo.
